# WiiPython

WiiPython is an application, which based on the [wii-cpython](https://github.com/lberwa/wii-cpython) libary, and means to run python code on the Wii


## Build
1. install [wii-cpython](https://github.com/lberwa/wii-cpython)

2. then build the application:
```bash
make
```

3. copy the content of sd_or_usb_card/ folder to your sd card
